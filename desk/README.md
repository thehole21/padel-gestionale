# PadelDesk OS
Avviare con Node 24 e `node desk/server.mjs`. Aprire http://localhost:3100. I dati sono persistenti nel database SQLite desk.sqlite. Eseguire un processo e un volume persistente per ogni circolo. Per accesso da pi� postazioni configurare DESK_PASSWORD e un reverse proxy HTTPS. Il nome utente � desk. DESK_DB seleziona il percorso del database. Il servizio richiede un host Node persistente, separato dall'hosting statico Vercel.

Il timer SYNC_MINUTES importa il calendario simulato del giorno. Nessuna scrittura su Playtomic. I movimenti utilizzano centesimi, identificativi di prenotazione e giocatore stabili. La cassa consente il saldo di una quota insoluta, anche tramite POST /api/payment con gli identificativi storici. Il riepilogo giornaliero distingue contanti, POS e credito.

Per WhatsApp Cloud API configurare WA_TOKEN, WA_PHONE_ID, WA_VERSION (versione abilitata sul proprio account), WA_SECRET (app secret), WA_VERIFY (token di verifica scelto dal gestore), WA_TEMPLATE (template italiano approvato con due parametri corpo: nome e orario, e pulsante quick reply PRENOTO). Configurare il callback HTTPS /webhook e sottoscrivere messages. Usare solo numeri con consenso alla ricezione di inviti. La prima accettazione chiude la ricerca.
